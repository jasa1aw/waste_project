# Раздельчик

Мобильное приложение для определения типа мусора и правильной его утилизации с помощью искусственного интеллекта.

## Описание

Раздельчик - это приложение, которое помогает пользователям правильно сортировать мусор. С помощью камеры телефона или загруженного изображения приложение определяет тип отходов и предоставляет информацию о том, как их правильно утилизировать.

### Основные функции

- 📸 Сканирование мусора через камеру
- 🖼️ Загрузка изображений из галереи
- 🤖 Анализ изображений с помощью AI
- 📋 Подробные инструкции по утилизации
- ⏱️ Информация о сроках разложения
- 🎨 Указание правильного контейнера для сортировки

## Установка

1. Убедитесь, что у вас установлен [Flutter](https://flutter.dev/docs/get-started/install)
2. Установите Android NDK версии 28.0.8114196:
   - Откройте Android Studio
   - Перейдите в SDK Manager
   - Выберите вкладку "SDK Tools"
   - Найдите и установите "NDK (Side by side)" версии 28.0.8114196
3. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/razdelchik.git
```
4. Перейдите в директорию проекта:
```bash
cd razdelchik
```
5. Установите зависимости:
```bash
flutter pub get
```
6. Запустите приложение:
```bash
flutter run
```

## Сборка APK

Для создания релизной версии APK выполните следующие команды:

1. Создание APK:
```bash
flutter build apk --release
```

2. Создание разделенных APK по архитектурам (рекомендуется):
```bash
flutter build apk --split-per-abi --release
```

После сборки APK файлы будут находиться в директории:
- Единый APK: `build/app/outputs/flutter-apk/app-release.apk`
- Разделенные APK:
  - `build/app/outputs/flutter-apk/app-armeabi-v7a-release.apk`
  - `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`
  - `build/app/outputs/flutter-apk/app-x86_64-release.apk`

## Использование

1. При первом запуске перейдите в настройки и получите API ключ на [OpenRouter](https://openrouter.ai/)
2. Вставьте полученный ключ в настройках приложения
3. На главном экране нажмите "Начать сканирование"
4. Сделайте фото или выберите изображение из галереи
5. Получите информацию о правильной утилизации отходов
